Sources

Evidence register

Every safety-relevant statement in The First 72 Hours is tied to a numbered source in this register. We publish it online rather than only in print so that it can be corrected quickly, and so that you can see when each source was last checked.

Entries are listed by their register number, which is the number printed beside the claim in the handbook. Each entry gives the issuing body, the title of the document, a link to the version we used, and the date we last confirmed that the link still resolved and the guidance had not changed. Where a source has been superseded, the entry says so and points to its replacement.

If you find a broken link, a newer edition, or a statement in the book that does not match its source, please email us with the register number.
